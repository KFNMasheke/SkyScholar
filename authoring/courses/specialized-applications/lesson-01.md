# Lesson 1: Choose the evidence before choosing the sensor

Course: Specialized Applications

Status: DRAFT. Original SkyScholar authoring; technical and instructional review pending.

Estimated study time: 20-30 minutes including the desk exercise (author estimate).

## Learning focus

Select a payload based on a client decision.

## Lesson

A facility manager sees a thermal image with a bright area on a roof and asks whether insulation has failed. The image is an observation under particular capture conditions. It does not by itself establish the material condition or the cause of the apparent temperature pattern.

Start with the decision to support. Does the client need a screening survey, a maintenance priority list, a documented change, or a specialist diagnosis? Each needs different evidence and competence. Define the assets, the decision-maker and the acceptance criteria before selecting a payload.

For any sensor, document acquisition conditions, settings, coverage and known limitations. A visually striking output may still be unsuitable for the question. Record plausible alternative explanations and the additional evidence needed to distinguish them. Where interpretation requires a specialist, identify that role in scope rather than allowing a polished report to imply expertise that has not been supplied.

A useful report separates observation, interpretation, confidence and recommended next step. Link every observation to an asset and source file. State where no usable evidence was collected. Missing coverage should never be silently converted into a clean bill of health.

Use fictional images or authorised sample data in this exercise. Build an evidence plan for one application, then explain why a different application would need a different validation method. The aim is a defensible workflow, not a promise that one sensor solves every industry problem.

## Desk exercise

Create a four-column evidence table for a fictional thermal roof screening: observation, possible explanations, verification required and handover recipient.

## Marking guide

Credit alternative explanations, traceable assets and appropriate specialist escalation. A temperature-looking colour must not become an unsupported defect diagnosis.

## Reflection

Name one assumption you would verify before applying this lesson to a real project. Identify the source or competent person who could resolve it.
