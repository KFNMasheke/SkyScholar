# Lesson 1: A map needs a measurement claim that can be checked

Course: Drone Mapping and Surveying

Status: DRAFT. Original SkyScholar authoring; technical and instructional review pending.

Estimated study time: 20-30 minutes including the desk exercise (author estimate).

## Learning focus

Distinguish a visual model from a validated measurement product.

## Lesson

A project manager asks whether a stockpile has grown since last month. A visual model can show its shape, but a volume comparison requires a consistent boundary, reference surface, coordinate system and method. Begin with the decision the measurement will support and the tolerance needed. Do not select settings from the word mapping alone.

Ground sampling distance describes the approximate ground size represented by a pixel under stated geometry. It is not the same as positional accuracy. Blur, weak geometry, calibration, control quality, surface texture and processing choices can all affect the delivered result. A fine-looking raster does not establish survey-grade performance.

Control points help relate a model to a reference frame. Independent checkpoints are withheld from that adjustment and used to assess performance. If every surveyed point is used to fit the model, the residuals at those fitted points cannot serve as an independent test. Record point roles before processing and keep their measurement provenance.

Horizontal and vertical references must be stated. A height may refer to an ellipsoid or to a local height system; mixing them can create a systematic offset. Record coordinate units and the transformation used, including any required grid files or assumptions. On-screen alignment is insufficient evidence of a correct transformation.

For the stockpile scenario, define the same base surface and boundary rules for both dates, inspect coverage, and report uncertainty and exclusions alongside the change. A delivery note should let another analyst understand what was measured and what remains uncertain.

## Desk exercise

Write a one-page quality plan for a fictional stockpile comparison, separating control and checkpoints and naming the information still required from the client.

## Marking guide

Expect explicit units, reference frames, independent checks, comparable base surfaces and a stated acceptance tolerance. GSD alone must not be presented as accuracy.

## Reflection

Name one assumption you would verify before applying this lesson to a real project. Identify the source or competent person who could resolve it.
