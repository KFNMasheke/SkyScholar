# Expanded SkyScholar self-study curricula

Each course contains a beginning-to-end self-study sequence: objectives, taught
lessons, an original worked example, a desk exercise, model answer, knowledge
checks, an illustrated concept map and a final project with marking criteria.
These are authored study courses, not approved practical training or proof of
regulatory syllabus completion. Technical/regulatory instructor review remains
pending. Operational flight exercises are not authorised by this material.

The radiotelephony lab is a fictional browser rehearsal. It does not connect to a
radio, file a flight plan, grant a clearance or evaluate a person's qualification.
English ICAO-style practice is distinguished from jurisdiction-specific procedures.
