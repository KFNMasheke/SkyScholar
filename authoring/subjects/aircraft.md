# Aircraft general knowledge: opening lesson

Status: DRAFT. Provisional South African subject; current syllabus mapping and competent review pending.

## Objective

Use configuration evidence and manufacturer instructions.

## Lesson

Aircraft knowledge starts with the actual configuration. Record the aircraft identity, installed components, software versions, payload and applicable documentation. Similar-looking aircraft may have different capabilities or limitations. Avoid transferring a procedure merely because two systems share a brand.

Understand each system by function. Positioning estimates location; attitude sensing supports orientation estimation; the command link carries control and status; propulsion supplies force. A status indicator can describe one function without proving that the entire system is ready. Review the meaning of indicators in the correct manual.

Maintenance and fault decisions require evidence. Record symptoms and changes before replacing components or altering settings. Separate an observation from a proposed cause. A battery with visible damage requires the appropriate manufacturer and site process, not a live experiment intended to see whether it still works.

A configuration record should allow another competent person to identify which manual and limitations apply. This foundation supports later aircraft-specific lessons. It supplies no universal maintenance procedure, calibration sequence or emergency control action.
