# Contributing

Practice access must remain free in this project. Keep Moodle core unmodified; implement extensions in the plugin and use Moodle APIs for state changes. Avoid learner data, credentials, confidential examination items and third-party paid question banks in commits or issues.

For content changes, provide an original/licensed question, rationale, authoritative reference, syllabus objective and review evidence. Code review does not substitute for aviation instructor review. Submit drafts first; operators publish only after review and staging checks.

Use GPL-3.0-or-later for contributed code and the demonstration fixtures, or explicitly identify compatible licences and upstream notices. Run the standalone tests, PHP syntax checks and isolated Moodle integration suite. Document any verification limits. Report security vulnerabilities privately rather than opening an issue containing exploit details or learner data.
