# Security reporting

Do not post credentials, personal information, learner answers or working exploit details in public issues.

Until a dedicated reporting mailbox is configured, contact the repository owner privately through their GitHub profile's published contact channel. If available, use GitHub's private vulnerability reporting. Do not assume that enabling this file enables GitHub's reporting feature.

Version 0.1.0 is a foundation release pending live-host acceptance and aviation content review. The deployment operator is responsible for patched Moodle/PHP/database versions, SMTP, administrator MFA, cron, backups, privacy configuration and an agreed incident-response contact.
